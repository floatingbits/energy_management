## Hypothesis
Establish a baseline for the existing physical power forecast.

## Result
The model provides a reasonable baseline but shows systematic deviations. These are correlated with the size of the asset, 
the efficiency of the panels and the temperature coefficient (last one might require a statistical test).  

## Next steps
We have several candidates for the biggest culprit that need further investigation: 
Shadowing, alignment (currently naive fixed value), structure type (tracker vs fixed), inverter efficiency, temperature
